# アジャイル開発ガイド

## 開発の進め方

### 1. スプリント計画
- 各スプリントの目標を設定
- スプリントバックログを作成
- 優先順位を決定
- 受け入れ基準を定義

### 2. ユーザーストーリーの作成
- 機能ごとにユーザーストーリーを作成
- 「As a ... I want to ... So that ...」形式で記述
- 受け入れ基準を明確化

### 3. 実装
- 小さな機能単位で実装
- テストを書きながら進める（将来的に）
- 動作確認を頻繁に行う

### 4. レビューと振り返り
- スプリント終了時に成果物をレビュー
- 振り返りを行い、改善点を次のスプリントに反映

## 開発フロー

```
要件定義
  ↓
スプリント計画
  ↓
ユーザーストーリー作成
  ↓
実装
  ↓
動作確認
  ↓
スプリントレビュー
  ↓
振り返り
  ↓
次のスプリント計画
```

## 1stスプリントの進め方

### ステップ1：環境構築
1. Docker環境の構築
   - フロントエンド（React）コンテナ
   - バックエンド（Node.js）コンテナ
   - データベース（MySQL）コンテナ
   - Docker Compose設定

### ステップ2：基本レイアウト実装
1. フロントエンドの基本構造
   - ヘッダーコンポーネント
   - サイドバーコンポーネント
   - メインコンテンツコンポーネント
   - ルーティング設定

### ステップ3：認証機能実装
1. データベース設計
   - ユーザーテーブル作成
2. バックエンド実装
   - ログインAPI
   - ログアウトAPI
   - セッション管理
3. フロントエンド実装
   - ログイン画面
   - 認証状態管理
   - ログアウト機能

### ステップ4：動作確認
1. ログイン→メインページ→ログアウトの流れを確認
2. 各機能が正常に動作することを確認

## ベストプラクティス

### 小さく進める
- 1つの機能を完全に実装してから次に進む
- 動作する状態を常に保つ

### 頻繁に確認する
- 実装したらすぐに動作確認
- 問題があればすぐに修正

### ドキュメントを更新する
- 実装した内容はドキュメントに反映
- 変更点は記録しておく
