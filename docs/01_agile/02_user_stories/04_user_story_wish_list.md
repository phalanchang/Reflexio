# 04. ユーザーストーリー：やりたいこと一覧表示

## ストーリー
**As a** ログインユーザー
**I want to** 登録した「やりたいこと」の一覧を見ることができる
**So that** 自分のウィッシュリストを把握し、何をやりたいかを確認できる

## 受け入れ基準

### 機能要件
- [ ] サイドバーに「やりたいこと」メニューが表示される
- [ ] メニュークリックでやりたいこと一覧画面に遷移する
- [ ] 自分が登録した「やりたいこと」が一覧表示される
- [ ] 各アイテムにタイトル、ステータス、優先度、期限が表示される
- [ ] ステータス別（未着手/進行中/完了）に視覚的に区別できる
- [ ] 優先度（高/中/低）が視覚的に区別できる
- [ ] アイテムが0件の場合、空状態のメッセージが表示される

### 非機能要件
- [ ] 自分のデータのみ取得される（他ユーザーのデータは見えない）
- [ ] 未ログイン時はログイン画面にリダイレクトされる
- [ ] API呼び出し中はローディング表示される

## 技術的詳細

### フロントエンド
- WishList コンポーネント
- API: GET /api/wishes（credentials: 'include'）
- ProtectedRoute で保護

### バックエンド
- GET /api/wishes エンドポイント
- requireAuth ミドルウェア適用
- req.session.userId でフィルタリング

### データベース
- SELECT * FROM wishes WHERE user_id = ? ORDER BY created_at DESC

## 優先順位
高（2ndスプリントで実装）
