# 05. ユーザーストーリー：やりたいこと追加

## ストーリー
**As a** ログインユーザー
**I want to** 新しい「やりたいこと」を登録できる
**So that** 自分のウィッシュリストに新しいアイテムを追加し、やりたいことを記録できる

## 受け入れ基準

### 機能要件
- [ ] 一覧画面に「追加」ボタンが表示される
- [ ] ボタンクリックで追加フォームが表示される
- [ ] タイトルを入力できる（必須）
- [ ] ステータスを選択できる（未着手/進行中/完了、デフォルト: 未着手）
- [ ] 優先度を選択できる（高/中/低、デフォルト: 中）
- [ ] 期限を設定できる（任意、日付ピッカー）
- [ ] メモを入力できる（任意、テキストエリア）
- [ ] 「保存」ボタンで登録される
- [ ] 「キャンセル」ボタンでフォームが閉じる
- [ ] 登録成功後、一覧に反映される
- [ ] タイトル未入力時にバリデーションエラーが表示される

### 非機能要件
- [ ] 登録成功時に成功メッセージが表示される
- [ ] エラー時にエラーメッセージが表示される

## 技術的詳細

### フロントエンド
- WishForm コンポーネント（モーダルまたはインライン）
- API: POST /api/wishes（credentials: 'include'）
- フォームバリデーション（タイトル必須）

### バックエンド
- POST /api/wishes エンドポイント
- requireAuth ミドルウェア適用
- サーバーサイドバリデーション
- user_id は req.session.userId から取得

### データベース
- INSERT INTO wishes (user_id, title, description, status, priority, due_date) VALUES (?, ?, ?, ?, ?, ?)

## 優先順位
高（2ndスプリントで実装）
