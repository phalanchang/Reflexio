下記のようなagent構成で開発を進めていきたいと考えています。
どのようにすればよいかイメージがわかないので、力を貸してもらいたいです。
・tmuxを使用して、windowを分割
・分割したwindowごとにclaude code を起動
・それぞれのwindowで起動したagentごとに役割を持たせる
・各agentの会話はyaml形式のファイルで行う
・ロールは下記を用意したいと考えている
  - ユーザーと会話するPMロール
  - PMから指示を受け、タスクを分解し、各エージェントに作業を割り振るPLロール
  - PMからの指示を受け、開発を担当するdeveloperロール
  - ドキュメントの整合性を担保するlibrarianロール
  - テストを担当するtesterロール
  - レビューを担当するreviewerロール
・また、それぞれの会話の方法としては、下記を想定している
  - エージェントにそれぞれIDを付与しておく
  - どのエージェントからどのエージェントへの指示（会話内容か）をファイル名で分かるようにしておく（例：PM_to_PL.yaml、PL_to_DEV1.yamlなど）
  - yamlファイルに会話の内容の記載が完了したら、会話を書いたことがわかる、ドキュメントにその内容を記載する
  - shellを起動しておき、ログファイルが更新されたら、会話を受け取る先のエージェントに対して、tmux の send-keys コマンドを使って、yamlファイルを読むように指示をする
