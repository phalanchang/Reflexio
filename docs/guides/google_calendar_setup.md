# Google Calendar API セットアップガイド

Reflexio で Google カレンダー連携を利用するには、Google Cloud Console で **OAuth Client ID** と **Client Secret** を取得し、Reflexio の設定画面に登録する必要があります。

このガイドでは、その手順をステップごとに説明します。

---

## ステップ1: Google Cloud Console にアクセス

1. ブラウザで [Google Cloud Console](https://console.cloud.google.com/) を開く
2. Google アカウントでログインする（Reflexio で利用する Google カレンダーと同じアカウントを推奨）

> **補足**: Google Cloud Console は無料で利用できます。クレジットカードの登録は不要です。

---

## ステップ2: プロジェクトの作成

1. 画面上部の **「プロジェクトを選択」** をクリック
2. 表示されるダイアログの右上にある **「新しいプロジェクト」** をクリック
3. 以下を入力:
   - **プロジェクト名**: 任意の名前（例: `Reflexio`）
   - **場所**: デフォルトのまま（「組織なし」）で OK
4. **「作成」** をクリック
5. 作成が完了したら、上部のプロジェクト選択で作成したプロジェクトが選ばれていることを確認

> **補足**: 既存のプロジェクトを利用しても問題ありません。その場合はステップ3に進んでください。

---

## ステップ3: Google Calendar API の有効化

1. 左側のナビゲーションメニューから **「APIとサービス」** → **「ライブラリ」** を選択
2. 検索バーに `Google Calendar API` と入力
3. 検索結果に表示される **「Google Calendar API」** をクリック
4. **「有効にする」** ボタンをクリック
5. 有効化が完了すると、API の管理画面に遷移する

> **補足**: 有効化には数秒〜数十秒かかる場合があります。

---

## ステップ4: OAuth 同意画面の設定

1. 左側のナビゲーションメニューから **「APIとサービス」** → **「OAuth 同意画面」** を選択
2. ユーザータイプで **「外部」** を選択し、**「作成」** をクリック
3. **「アプリ情報」** を入力:
   - **アプリ名**: 任意の名前（例: `Reflexio`）
   - **ユーザーサポートメール**: 自分のメールアドレスを選択
   - **デベロッパーの連絡先情報**: 自分のメールアドレスを入力
4. **「保存して次へ」** をクリック
5. **「スコープ」** 画面で:
   - **「スコープを追加または削除」** をクリック
   - フィルタに `calendar` と入力
   - `.../auth/calendar.readonly`（Google Calendar API, 読み取り専用）にチェックを入れる
   - **「更新」** をクリック
   - **「保存して次へ」** をクリック
6. **「テストユーザー」** 画面で:
   - **「＋ ADD USERS」** をクリック
   - 自分の Gmail アドレスを入力して **「追加」**
   - **「保存して次へ」** をクリック
7. 最後に概要を確認し、**「ダッシュボードに戻る」** をクリック

> **補足**: テストモード（公開ステータスが「テスト」）の状態で利用します。テストモードではテストユーザーとして追加したアカウントのみが利用できます。個人利用であればこれで十分です。

---

## ステップ5: OAuth クライアント ID の作成

1. 左側のナビゲーションメニューから **「APIとサービス」** → **「認証情報」** を選択
2. 上部の **「＋ 認証情報を作成」** をクリック
3. ドロップダウンから **「OAuth クライアント ID」** を選択
4. 以下を入力:
   - **アプリケーションの種類**: **「ウェブ アプリケーション」** を選択
   - **名前**: 任意の名前（例: `Reflexio Web Client`）
5. **「承認済みのリダイレクト URI」** セクションで:
   - **「＋ URI を追加」** をクリック
   - 以下の URI を**正確に**入力:
     ```
     http://localhost:3003/auth/google/callback
     ```
6. **「作成」** をクリック

> **重要**: リダイレクト URI は **1文字でも間違うとエラー**になります。コピー＆ペーストで正確に入力してください。`http`（`https` ではない）、ポート番号 `3003`、パス `/auth/google/callback` のすべてが正確であることを確認してください。

---

## ステップ6: Client ID と Client Secret のコピー

1. クライアント ID の作成が完了すると、**「OAuth クライアントを作成しました」** ダイアログが表示される
2. 以下の2つの値をコピーして、安全な場所（メモ帳など）に一時保管:
   - **クライアント ID** — `xxxxxxxxxxxx.apps.googleusercontent.com` の形式
   - **クライアント シークレット** — `GOCSPX-xxxxxxxxxxxx` の形式
3. **「OK」** をクリックしてダイアログを閉じる

> **補足**: この画面を閉じた後も、「認証情報」ページからクライアント ID をクリックすれば再確認できます。ただし、Client Secret はこのタイミングでコピーしておくことを推奨します。

---

## ステップ7: Reflexio の設定画面に貼り付け

1. Reflexio にログイン（`http://localhost:3003`）
2. サイドバーの **「⚙️ 設定」** をクリック
3. **Google OAuth 設定** フォームに以下を入力:
   - **Client ID**: ステップ6でコピーした クライアント ID
   - **Client Secret**: ステップ6でコピーした クライアント シークレット
4. **「保存」** ボタンをクリック
5. 保存が成功したら、サイドバーの **「📊 ダッシュボード」** に移動
6. **「Google カレンダーを接続」** ボタンをクリック
7. Google アカウントの認証画面が表示されるので、許可して接続を完了

> **補足**: 接続が完了すると、ダッシュボードに Google カレンダーの予定が棒グラフで表示されます。

---

## 注意事項

### 無料枠について

Google Calendar API は個人利用レベルであれば **無料枠内** で利用できます。1日あたりのリクエスト上限は十分に大きいため、通常の個人利用で課金が発生することはありません。

### テストモードの制限

- テストモード（未公開状態）では、テストユーザーとして追加したアカウントのみが利用できます
- 最大 **100ユーザー** まで追加可能です（個人利用には十分）
- 本番公開（Google の審査）は個人利用では不要です

### 「アプリが未確認です」の警告

Google アカウント認証時に **「このアプリは Google で確認されていません」** という警告が表示されることがあります。これはテストモードでは正常な動作です。

- **「詳細」** → **「Reflexio（安全ではないページ）に移動」** をクリックして続行してください
- 自分で作成した OAuth クライアントを使用しているため、セキュリティ上の問題はありません

### リダイレクト URI について

- 本ガイドの URI（`http://localhost:3003/auth/google/callback`）はローカル開発環境用です
- 本番環境にデプロイする場合は、Google Cloud Console の認証情報で **リダイレクト URI を本番用の URL に変更** する必要があります
- WSL2 環境で private IP（172.x.x.x など）を使ってアプリにアクセスしている場合でも、
  リダイレクト URI は `http://localhost:3003/auth/google/callback` のまま使用してください。
  WSL2 はポートフォワーディングにより `localhost:3003` でも同じアプリにアクセスできます。

## トラブルシューティング

### 「redirect_uri_mismatch」エラーが出る

- Google Cloud Console の「認証情報」→ 作成したクライアント ID → **「承認済みのリダイレクト URI」** を確認してください
- `http://localhost:3003/auth/google/callback` が正確に登録されていることを確認
- 設定変更後、反映までに数分かかる場合があります

### 「device_id and device_name are required for private IP」エラーが出る

- Google OAuth はウェブアプリケーションの redirect_uri として **private IP（172.x.x.x、192.168.x.x、10.x.x.x）を許可していません**
- redirect_uri は必ず `http://localhost:3003/auth/google/callback` に設定してください
- WSL2 環境で `172.x.x.x:3003` のような IP アドレスでアクセスしている場合でも、
  OAuth コールバックは `localhost:3003` に正しくリダイレクトされます（WSL2 の自動ポートフォワーディング機能）
- Google Cloud Console の「承認済みのリダイレクト URI」に private IP を追加しないでください

### 「access_denied」エラーが出る

- OAuth 同意画面の **「テストユーザー」** に自分の Gmail アドレスが追加されているか確認してください

### Google カレンダーの予定が表示されない

- Google カレンダーに予定が登録されているか確認してください
- ダッシュボードの期間切替（7日 / 週 / 月）を変更して、予定のある期間を表示してみてください
