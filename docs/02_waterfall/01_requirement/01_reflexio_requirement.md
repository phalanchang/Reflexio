# 01. Reflexio 要件定義書

## 概要
Reflexioは、個人の生活をサポートする統合型Webアプリケーションです。ログイン機能、ダッシュボード、家計簿、ノート管理、ActiveRecall、タスク管理などの機能を提供し、ユーザーの日々の生活を効率的に管理できるようにします。

## プロジェクト情報

### プロジェクト名
Reflexio (Reflexio Reflecton Myself)

### 開発手法
アジャイル開発方式（段階的な機能追加）

### 開発環境
- OS: Windows + WSL
- インフラ: Docker（各サービスをコンテナ化）

## 技術スタック

### フロントエンド
- **フレームワーク**: React
- **実行環境**: Docker Container

### バックエンド
- **ランタイム**: Node.js
- **実行環境**: Docker Container

### データベース
- **DBMS**: MySQL
- **実行環境**: Docker Container

### インフラ構成
- フロントエンド、バックエンド、データベースをそれぞれDockerコンテナとして構築
- Docker間で通信を行い、サービスを提供

## 機能要件

### 1. ログイン機能
- ユーザー認証機能
- セッション管理
- パスワード管理

### 2. ダッシュボード機能
- 各種機能へのアクセスポイント
- 統合的な情報表示
- クイックアクセス機能

### 3. 家計簿機能
- 収入・支出の記録
- カテゴリ別の管理
- 月次・年次の集計・分析
- グラフ表示

### 4. ノート管理機能
- ノートの作成・編集・削除
- カテゴリ・タグによる分類
- 検索機能
- マークダウン対応（想定）

### 5. ActiveRecall機能
- 学習コンテンツの作成
- 復習スケジュール管理
- 記憶定着のための反復学習機能
- 進捗管理

### 6. タスク管理機能
- タスクの作成・編集・削除
- 優先度設定
- 期日管理
- ステータス管理（未着手、進行中、完了など）
- カテゴリ・プロジェクト別の分類

## 非機能要件

### パフォーマンス

- APIレスポンス時間の最適化

### セキュリティ
- パスワードのハッシュ化
- セッション管理の適切な実装
- SQLインジェクション対策

### 可用性
- Dockerコンテナによる環境の統一
- エラーハンドリングの実装

### 保守性
- コードの可読性
- ドキュメントの整備
- テストの実装（将来的に）

## 開発方針

### 段階的な開発
- アジャイル方式で機能を段階的に追加
- 最初は最小限の機能から開始
- ユーザーフィードバックを反映しながら拡張

### 優先順位（想定）
1. ログイン機能
2. ダッシュボード機能
3. タスク管理機能
4. ノート管理機能
5. 家計簿機能
6. ActiveRecall機能

※ 優先順位は開発の進捗に応じて変更可能

## 制約事項

### 環境制約
- Windows環境での開発
- WSLを使用した実行
- Dockerコンテナによる環境構築

### 技術制約
- フロントエンド: React
- バックエンド: Node.js
- データベース: MySQL

## UI/UX設計

### 基本画面構成

#### レイアウト構造
```
┌─────────────────────────────────────────┐
│          ヘッダー（高さ40px）            │
├──────────┬──────────────────────────────┤
│          │                              │
│ サイドバー│     メインコンテンツ          │
│（幅250px）│     （残りの領域）            │
│          │                              │
│          │                              │
└──────────┴──────────────────────────────┘
```

#### ヘッダー
- **位置**: 画面上部
- **高さ**: 40px
- **機能**: アプリケーションの基本情報表示、ログアウトボタンなど

#### サイドバー
- **位置**: 画面左側
- **幅**: 250px
- **機能**: 
  - 各機能へのナビゲーション（ログイン機能以外）
  - ダッシュボード
  - 家計簿
  - ノート管理
  - ActiveRecall
  - タスク管理
- **動作**: クリックでメインコンテンツ部分に対応したコンテンツを表示

#### メインコンテンツ
- **位置**: ヘッダーとサイドバー以外の領域
- **機能**: 選択された機能のコンテンツを表示

### 1stスプリントでの画面フロー

1. **ログイン画面**
   - ユーザー名・パスワード入力
   - ログインボタン

2. **メインページ（ログイン後）**
   - ヘッダー（高さ40px）
   - サイドバー（幅250px）
   - メインコンテンツ（初期表示はダッシュボード想定）

3. **ログアウト**
   - ヘッダーからログアウトボタンをクリック
   - ログイン画面に戻る
