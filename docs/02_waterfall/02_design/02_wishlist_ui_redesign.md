# 02. やりたいこと画面 UI改善設計書

## 概要
ペルソナ（36歳 PM/エンジニア）に基づき、「やりたいこと」画面のUI/UXを全面的に改善する。

## 現状分析

### キャプチャ元
- Figma: [Reflexio - Wishes Page Capture](https://www.figma.com/design/RrFxdB8pBJVPxNMjjBdWam/Reflexio---Wishes-Page-Capture?node-id=3-2)
- 対象コンポーネント: `WishList.js`, `WishFilter.js`, `WishList.css`, `WishFilter.css`

### 問題点一覧

| # | 問題 | ペルソナ原則違反 | 影響度 |
|---|---|---|---|
| P1 | **画面利用率が低い**: `max-width: 800px` で画面の約55%が未使用 | 情報ファースト | 高 |
| P2 | **情報密度が低い**: カード1件=80-90px。10件でスクロール必要 | 情報ファースト / スキャン可能 | 高 |
| P3 | **全体像が見えない**: ステータス別の件数集計がない | スキャン可能 | 高 |
| P4 | **ソート機能なし**: 期限順・優先度順に並べ替えできない | 3クリック以内 | 中 |
| P5 | **テキスト検索なし**: タイトル・メモの全文検索ができない | 3クリック以内 | 中 |
| P6 | **ステータスフィルタなし**: 未着手/進行中/完了で絞り込めない | 3クリック以内 | 中 |
| P7 | **常時表示のアクションボタン**: 編集/削除が全カードに常時表示で冗長 | コンテキスト保持 | 低 |
| P8 | **期限の視覚強調なし**: 期限切れ・直近の期限が一目でわからない | スキャン可能 | 中 |

## 改善設計

### 改善1: テーブルビュー（情報密度3倍）

**Before**: カードレイアウト（1件 = 80-90px）→ 画面内に2-3件
**After**: テーブルレイアウト（1件 = 36px）→ 画面内に12-15件

```
┌──┬────────────────────────┬────────┬─────┬──────┬───────┬────┐
│□ │ タイトル               │ステータス│優先度│ タグ  │ 期限  │ ⋯ │
├──┼────────────────────────┼────────┼─────┼──────┼───────┼────┤
│□ │ AIの現状の整理...      │ 未着手  │  中  │ AI   │ 3/2   │ ⋯ │
│□ │ OpenClawSetup          │ 完了    │  高  │AI,OC │ 2/22  │ ⋯ │
│□ │ Notion連携テスト       │ 進行中  │  高  │ Bot  │ 3/5   │ ⋯ │
└──┴────────────────────────┴────────┴─────┴──────┴───────┴────┘
```

**実装方針**:
- デフォルトはテーブルビュー
- カードビューも残し、切替トグルを提供（☰ / ▦）
- テーブル行クリックで詳細をサイドパネルまたはインライン展開

**CSS変更**:
- `.wish-list-container` の `max-width: 800px` → 削除（全幅）
- 新規 `.wish-table` クラス追加
- `.wish-item` → `.wish-table-row`（36px高さ）

### 改善2: ステータスサマリーバー

ページ上部に件数サマリーを常時表示。クリックでフィルタ連動。

```
やりたいこと  全12件
[未着手 4] [進行中 5] [完了 3]     ← クリックでフィルタ
```

**実装方針**:
- `WishList.js` 内で `wishes` 配列から集計
- 各バッジクリックで `selectedStatuses` を切替
- 色はステータスバッジと統一（グレー/青/緑）

### 改善3: 全幅レイアウト + サイドバー折りたたみ

**Before**: サイドバー250px + コンテンツ max-width:800px = 画面55%が空白
**After**: サイドバー折りたたみ（40px）+ コンテンツ全幅

**実装方針**:
- `Sidebar.js` にトグルボタン追加
- 折りたたみ時: アイコンのみ表示（40px幅）
- 展開時: 従来通り250px
- 状態を `localStorage` に保存
- CSS: `.sidebar.collapsed { width: 40px; }`

### 改善4: 統合ツールバー

フィルタ・検索・ソート・ビュー切替を1行に統合。

```
[🔍 検索...          ] [タグ▼] [優先度▼] [ステータス▼] [並び替え▼]  [☰][▦]
```

**実装方針**:
- `WishFilter.js` → `WishToolbar.js` にリネーム・拡張
- ドロップダウンフィルタ（省スペース）
- テキスト検索（タイトル + description 部分一致）
- ソートオプション: 期限昇順/降順、優先度、ステータス、作成日
- ビュー切替: テーブル / カード

### 改善5: 期限の視覚強調

PMにとって期限管理は最重要。期限を色と太さで即認知。

| 条件 | 表示 | CSS |
|---|---|---|
| 期限切れ | **赤太字** | `color: #c62828; font-weight: 700;` |
| 今日 | **オレンジ太字** | `color: #e65100; font-weight: 700;` |
| 3日以内 | 黄色 | `color: #f57f17;` |
| それ以降 | グレー | `color: #888;` |
| 期限なし | `-` | `color: #ccc;` |

**実装方針**:
- `getDueDateStyle(dateString)` ヘルパー関数を追加
- テーブル行に期限クラスを適用

### 改善6: コンテキストメニュー（⋯）

常時表示の「編集」「削除」ボタンをメニューに集約。

**Before**: 各カードに常時 [編集] [削除] ボタン表示
**After**: `⋯` アイコン → ホバー/クリックでドロップダウン

```
⋯ クリック時:
  ┌──────────┐
  │ 📝 編集   │
  │ 🔄 ステータス変更 │
  │ ── ────── │
  │ 🗑 削除   │
  └──────────┘
```

**実装方針**:
- `ActionMenu.js` 新規コンポーネント
- ドロップダウンメニュー（外部クリックで閉じる）
- テーブル行ホバー時に編集アイコンを薄く表示（クイック操作）

### 改善7: 一括操作（バルクアクション）

チェックボックスで複数選択 → 一括操作。

**操作**:
- 一括ステータス変更（未着手→進行中、進行中→完了）
- 一括削除
- 一括タグ追加

**実装方針**:
- `selectedIds` state 管理
- ヘッダーチェックボックスで全選択/全解除
- 選択時にフローティングアクションバー表示

### 改善8: キーボードショートカット

パワーユーザー向け。

| キー | アクション |
|---|---|
| `N` | 新規追加 |
| `E` | 選択行を編集 |
| `Delete` | 選択行を削除 |
| `↑` / `↓` | 行移動 |
| `/` | 検索フォーカス |
| `Escape` | フォーム/モーダル閉じる |
| `Space` | チェックボックス切替 |

**実装方針**:
- `useKeyboardShortcuts` カスタムフック
- フォーム入力中は無効化
- `?` キーでショートカットヘルプ表示
